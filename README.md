# Lagoa

**Русский** | [English](README.en.md)

Личный ИИ-ассистент с веб-чатом. Мой первый пет-проект.

Вы задаёте вопрос в веб-чате, бэкенд отправляет его нейросети вместе с контекстом прошлого диалога, сохраняет вопрос и ответ в базу данных и возвращает ответ. Lagoa помнит, о чём вы говорили раньше, а при следующем открытии чата вся история подгружается из базы.

Lagoa умеет работать с разными нейросетями: сейчас подключены **Groq** (используется по умолчанию) и **Google Gemini**.

## Возможности

- Чат с нейросетью через веб-интерфейс
- **Несколько нейросетей:** Groq и Gemini за общим интерфейсом, переключение одной строкой
- **Память диалога:** Lagoa помнит контекст прошлых сообщений
- Сохранение истории запросов в SQLite
- История привязана к IP-адресу пользователя
- Ответы отображаются с форматированием (списки, жирный текст, блоки кода)
- Адаптивный интерфейс для компьютера и телефона
- Интерфейс на русском и английском с переключателем языка

## Как Lagoa помнит контекст

Языковые модели не хранят память между запросами, поэтому контекст передаётся вместе с каждым вопросом. Чтобы запрос не разрастался бесконечно, история делится на две части:

- **последние сообщения** (по умолчанию 10) отправляются модели дословно;
- **более старые сообщения** сжимаются в краткое резюме: важные факты о пользователе, его задачи и договорённости. Резюме хранится в базе, передаётся модели как системная инструкция и обновляется порциями, когда накапливаются новые старые сообщения.

Так ассистент помнит и свежие детали, и общую картину разговора, а размер запроса остаётся небольшим. Число дословных сообщений и размер порции для сжатия настраиваются в `config.py` (`keep_last` и `summarise_every`).

## Стек

- **Python 3.14**
- **FastAPI** — REST API
- **Uvicorn** — ASGI-сервер
- **SQLAlchemy 2** — ORM, база данных SQLite
- **groq** — клиент для Groq API
- **google-genai** — клиент для Gemini API
- **python-dotenv** — загрузка ключей API из `.env`
- **HTML / CSS / JavaScript** — фронтенд без фреймворков
- **uv** — управление зависимостями

## Нейросети

Клиенты нейросетей наследуются от абстрактного класса `Client`. Чтобы подключить другую модель, достаточно написать новый класс с методом `generate`. Остальной код работает с любым клиентом одинаково.

Модель выбирается в `main.py` одной строкой:

```python
client: Client = GroqClient(api_key=cfg.groq_api_key)        # Groq (по умолчанию)
# client: Client = GeminiClient(api_key=cfg.gemini_api_key)  # Gemini
```

Конкретную модель можно передать параметром `model`, например `GroqClient(api_key=..., model="...")`. Список доступных моделей есть в документации [Groq](https://console.groq.com/docs/models) и [Gemini](https://ai.google.dev/gemini-api/docs/models).

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/maxbaderishere/LagoaAssistant.git
cd LagoaAssistant
```

### 2. Установить зависимости

Нужен установленный [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

### 3. Добавить ключи API

Создайте в корне проекта файл `.env`. Достаточно ключа той нейросети, которую вы используете:

```
GROQ_API_KEY=ваш_ключ_groq
GEMINI_API_KEY=ваш_ключ_gemini
```

Ключ Groq можно получить в [консоли Groq](https://console.groq.com/keys), ключ Gemini — в [Google AI Studio](https://aistudio.google.com/apikey).

### 4. Запустить бэкенд

```bash
uv run uvicorn main:app --reload
```

API будет доступно на http://localhost:8000, интерактивная документация — на http://localhost:8000/docs.

### 5. Запустить фронтенд

Фронтенд должен работать на порту 5500 (этот адрес разрешён в настройках CORS). Раздавать нужно только папку `frontend/`, например так:

```bash
python -m http.server 5500 -d frontend
```

После этого откройте http://localhost:5500/index.html. Через Live Server в VS Code откройте файл `frontend/index.html`.

## API

| Метод | Путь        | Описание                                           |
|-------|-------------|----------------------------------------------------|
| GET   | `/requests` | Вся история запросов текущего пользователя (по IP) |
| POST  | `/requests` | Отправить вопрос нейросети с учётом контекста      |

Пример запроса:

```bash
curl -X POST http://localhost:8000/requests \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Привет! Кто ты?"}'
```

Ответ:

```json
{"answer": "Привет! Я — большая языковая модель..."}
```

## Ограничения

- Пользователи различаются только по IP-адресу, авторизации нет.
- У каждого пользователя один общий диалог: создавать отдельные чаты пока нельзя.
- Резюме старых сообщений теряет мелкие детали: модель помнит суть, но не дословные формулировки.
- Модель выбирается в коде, а не в интерфейсе.
